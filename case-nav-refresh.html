Accessibility + UX

Inclusive Navigation Refresh

Refining information architecture and interaction states to improve clarity across key user journeys.

Role

UX/UI Engineer & Accessibility Specialist

Timeline

6 weeks

Tools

WCAG 2.1, IA, Usability Testing, Figma

Overview

The Challenge

A product's navigation had grown organically, creating redundant paths, unclear labels, and interaction states that failed accessibility standards. Users — particularly those with disabilities — were getting lost and abandoning tasks.

Project Value

Navigation that works for everyone

By applying inclusive design principles to the navigation system — clearer labels, logical structure, visible focus states, and consistent interaction patterns — the product becomes more usable for all users, regardless of ability.

Key Scenarios

🧭

Wayfinding clarity

Users always know where they are, where they came from, and where they can go — through consistent breadcrumbs, page titles, and active states.

🎹

Keyboard navigation

All navigation elements are fully operable by keyboard with clearly visible focus indicators and a logical tab sequence.

📢

Screen reader experience

Landmark regions, ARIA labels, and skip links create a structured, efficient experience for screen reader users.

Features & Process

How It Came Together

IA audit and card sorting

Ran a remote card sorting study with 18 participants to validate the existing navigation structure and identify mental model gaps.

Interaction state redesign

Redesigned all interactive states — hover, focus, active, disabled — to meet WCAG contrast requirements and communicate state clearly across contexts.

Usability testing with diverse participants

Conducted usability sessions with six participants, including two keyboard-only users and one screen reader user, to validate the redesigned navigation.
