UX/UI Design

Outdoor Pikes Peak Datahub Redesign

Navigation and interface structure improvements for an outdoor resource platform.

Role

UX/UI Engineer

Timeline

6 weeks

Tools

Figma, UX Research, HTML/CSS

Overview

The Challenge

The Outdoor Pikes Peak Datahub had grown organically over time, resulting in a fragmented navigation structure and inconsistent visual hierarchy that made it difficult for users to find critical outdoor resource information quickly.

Project Value

Seamless access to outdoor resources

By restructuring the information architecture and simplifying navigation patterns, users can now move between resource categories fluidly — reducing time-to-find and increasing satisfaction for hikers, cyclists, and outdoor enthusiasts.

Key Scenarios

🗺️

Browse resources by category

Users can filter trails, conditions, and events with a streamlined category navigation that surfaces the most relevant content.

📍

Find location details quickly

Improved card layouts and clear hierarchy let users scan key details — distance, elevation, difficulty — at a glance.

📱

Access on any device

Responsive layouts ensure the redesigned experience works equally well on desktop, tablet, and mobile.

Features & Process

How It Came Together

Restructured information architecture

Conducted card sorting and tree testing with real users to reorganize the site's content model. The new structure reduced navigation depth from four levels to two.

Accessible component system

Built a lightweight component library in Figma that ensured consistent spacing, color contrast ratios above WCAG AA, and clear focus states throughout the interface.

Usability testing & iteration

Conducted two rounds of moderated usability testing with five participants each, iterating on key flows based on observed pain points and task completion rates.

Outcomes
