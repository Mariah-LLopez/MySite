Portfolio Website

View Live ↗ View Document ↗

Responsive, accessible storytelling portfolio designed and built from scratch.

Role

Designer & Front-End Developer

Timeline

4 weeks

Tools

HTML, CSS, JavaScript, GitHub Pages

Overview

The Challenge

Existing portfolio templates didn't reflect a multidisciplinary identity spanning UX, writing, and business analysis. A custom-built solution was needed to communicate range, technical competence, and design sensibility simultaneously.

Project Value

One site, many disciplines

A hand-coded portfolio serves dual purpose — demonstrating technical front-end capability while showcasing the breadth of multidisciplinary work. Visitors from any background can quickly find what they're looking for through thoughtful IA and filtering.

Key Scenarios

🎨

Design system creation

Built a custom design system with CSS custom properties, ensuring consistent color, typography, spacing, and component patterns throughout.

⚡

Performance optimization

Implemented lazy loading, optimized asset delivery, and minimal JavaScript to achieve fast load times on any connection.

♿

Accessibility-first build

Every interactive element was built with keyboard navigation, focus management, and screen reader compatibility from the start.

Features & Process

How It Came Together

Design system with CSS custom properties

Created a token-based design system using CSS variables for color, spacing, and typography — enabling consistent theming across light and dark modes.

Interactive animations and micro-interactions

Added reveal animations, magnetic buttons, octopus canvas art, and a keyboard interaction Easter egg to create a memorable, playful experience.

Multi-page responsive architecture

Structured a clean multi-page site with shared navigation, footers, and JavaScript functionality — deployed via GitHub Pages with a custom domain.
