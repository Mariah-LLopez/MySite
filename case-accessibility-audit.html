Accessibility Audit

Comprehensive barrier analysis, testing, and recommendations for a digital product.

Role

Accessibility Specialist & UX Researcher

Timeline

5 weeks

Tools

WAVE, WCAG 2.1, Axe, Screen Reader Testing

Overview

The Challenge

A digital product team needed an independent accessibility review before a major public launch. Internal teams lacked the expertise to identify all barrier types — particularly around screen reader compatibility, keyboard navigation, and cognitive load.

Project Value

Accessible experiences for all users

By systematically testing against WCAG 2.1 AA criteria and documenting findings with prioritized remediation recommendations, the team received a clear, actionable roadmap to eliminate access barriers before launch.

Key Scenarios

🔍

Automated scanning

Used WAVE and Axe to identify programmatic issues including missing labels, contrast failures, and invalid ARIA roles across all major flows.

⌨️

Keyboard navigation testing

Manually tested every interactive element for keyboard operability, focus visibility, and logical tab order.

🔊

Screen reader evaluation

Tested with NVDA and VoiceOver to identify announcement gaps, confusing read orders, and missing context for non-visual users.

Features & Process

How It Came Together

Heuristic evaluation

Evaluated the product against WCAG 2.1 Levels A and AA across all four principles: Perceivable, Operable, Understandable, and Robust.

User testing with assistive technology

Recruited two participants who rely on screen readers daily to complete core tasks, capturing real-world barriers that automated tools miss.

Prioritized remediation report

Delivered a 40-page report organizing findings by severity (Critical, Major, Minor), with code-level recommendations and estimated effort for each fix.
