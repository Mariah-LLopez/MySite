Pikes Peak Library Localization

View Live ↗

Spanish localization, accessibility improvements, and clearer content structure for a public library system.

Role

Technical Writer & UX Researcher

Timeline

8 weeks

Tools

Plain Language, Localization, WAVE, WCAG

Overview

The Challenge

The Pikes Peak Library District served a growing Spanish-speaking community but lacked accessible, properly translated content. English-only pages and poor contrast ratios created barriers that prevented equitable access to library resources.

Project Value

Equitable access for every community member

By localizing key resources into Spanish and fixing accessibility barriers, the library can now serve Spanish-speaking patrons with dignity — ensuring information about programs, services, and hours is always clear and findable.

Key Scenarios

🌐

Spanish-language browsing

Community members can now access program descriptions, event listings, and service information in clear, plain-language Spanish.

♿

Accessible navigation

Fixed contrast ratios, added skip links, and improved focus management so screen reader and keyboard users can navigate independently.

📖

Plain language rewrite

Core instructional content was rewritten at a 6th grade reading level in both English and Spanish, following plain language guidelines.

Features & Process

How It Came Together

Content audit and gap analysis

Reviewed 200+ pages to identify English-only content, high-barrier language, and failed accessibility checkpoints using WAVE and manual testing.

Translation and plain language

Translated 40 priority pages into Spanish while applying plain language principles — shorter sentences, active voice, and clear headings — to both language versions.

Accessibility remediation

Resolved WCAG 2.1 AA failures including color contrast, missing alt text, form labeling issues, and keyboard trap scenarios.
